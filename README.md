# ui-lab

Small UI components I build while learning interaction design, each one on its own canvas at [lab.xevrion.dev](https://lab.xevrion.dev).

Most of them start as a question about why some interface feels good, and end as a component that tries to get the unseen details right: the easing, the press feedback, what happens at the edges. Every one works in light and dark.

## Running it

```bash
bun install
bun dev
```

`bun run new <slug>` adds a component and registers it on the index. The project is built from [design-scaffold](https://github.com/xevrion/design-scaffold), whose README covers how the lab, the tokens and the theme toggle fit together.
